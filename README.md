# Quickly
The bimO Quick Tools extension for pyRevit is a thoughtfully crafted productivity booster designed by an architect who embraces efficiency. Built with the idea that smart work beats hard work, this tool is aimed at helping fellow architects streamline their workflow and maximize productivity. Whether you're managing complex designs or handling repetitive tasks, bimO Quick Tools brings a collection of features to make life easier—allowing architects to focus more on creativity and design, and less on tedious processes. It's the perfect companion for those who appreciate working smarter, not harder.
